# Connect Four (Quatro em Linha)

Trabalho prático desenvolvido para a disciplina de Introdução à Ciência da Computação da Universidade Federal de Santa Catarina (UFSC). O projeto consiste na implementação do clássico jogo de tabuleiro Connect Four em Python, integrando regras lógicas de gravidade, verificação de vitórias matriciais e uma interface gráfica interativa baseada na biblioteca FreeSimpleGUI.

## Tecnologias Utilizadas
- **Python 3** (Linguagem de programação)
- **FreeSimpleGUI** (Biblioteca para construção da interface gráfica de usuário)
- **Git & GitHub** (Controle de versão e versionamento em blocos sequenciais)

## Como Executar
1. Certifique-se de possuir o Python instalado em seu ambiente.
2. Instale a dependência gráfica necessária executando o gerenciador de pacotes ou utilizando o arquivo de configuração do projeto (`pyproject.toml`).
3. Execute o script principal através do terminal:
   ```bash
   python connect_four.py
